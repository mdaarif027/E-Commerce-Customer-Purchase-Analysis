# E-Commerce Customer Purchase Analysis using Python

## 📌 Project Overview

This project focuses on analyzing an e-commerce customer purchase dataset using Python. The objective is to perform data exploration, analysis, and interactive data visualization to understand customer purchasing behavior and identify useful patterns in the dataset.

The analysis covers purchase prices, customer languages, companies, credit card providers, browser information, job titles, email providers, and AM/PM purchasing behavior.

---

## 🛠️ Tools & Technologies

* Python
* Pandas
* Plotly Express
* Plotly Graph Objects
* Jupyter Notebook

---

## 📂 Dataset

The dataset contains **10,000 customer records** and **14 columns** related to customer and purchase information.

### Main Columns

* Address
* Lot
* AM or PM
* Browser Info
* Company
* Credit Card
* CC Exp Date
* CC Security Code
* CC Provider
* Email
* Job
* IP Address
* Language
* Purchase Price

---

## 🔍 Data Analysis Performed

The following analysis was performed using Python and Pandas:

1. Displayed the top 10 rows of the dataset.
2. Checked the last 10 rows of the dataset.
3. Checked the data type of each column.
4. Checked for null values in the dataset.
5. Checked the number of rows and columns.
6. Found the highest and lowest purchase prices.
7. Calculated the average purchase price.
8. Counted customers using French (`fr`) as their language.
9. Identified job titles containing the word **"Engineer"**.
10. Found the email address associated with a specific IP address.
11. Counted Mastercard customers who made purchases above 50.
12. Found the email address associated with a specific credit card number.
13. Compared AM vs PM purchasing behavior.
14. Counted customers whose credit cards expire in 2020.
15. Identified the top 5 most popular email providers.
